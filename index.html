Sobre mim

Dev em
formação

Em 2024 dei o primeiro passo na programação ingressando num curso de desenvolvimento — e desde então não parei mais. Comecei do zero, aprendendo a lógica por trás do código com a Linguagem C, estruturas de dados com MySQL, e logo evoluí para o universo web com HTML, CSS e JavaScript.

Ao longo da jornada, fui construindo projetos reais: landing pages, lojas virtuais, sites institucionais e interfaces interativas. Cada projeto foi uma oportunidade de aprender mais, refinar o código e entender melhor como entregar uma experiência digital de qualidade.

Hoje expando minha atuação para o back-end com Node.js e Java, construindo APIs e lógica de servidor — o que me posiciona cada vez mais perto de trabalhar com o stack completo de uma aplicação. Gosto de código limpo, design com propósito e de transformar ideias em produtos reais.
